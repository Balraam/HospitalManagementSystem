# HospitalManagementSystem
A code repo for HMS used tech stack ReactJS, CSS, HTML Frontend 

# Tech Stack: React.js, HTML, CSS, JavaScript, Json-server 

# Key Highlights: 
- Developed interactive and reusable UI components using React.js and hooks (useState, useEffect). 
- Implemented React Router for smooth navigation between pages. 
- Designed forms and tables for adding and displaying hospital data dynamically. 
- Focused on component-based architecture and responsive layout using CSS. 
- Worked on improving user experience (UX) and ensuring clean, maintainable code .
- This project was developed as a self-learning initiative to strengthen my React.js frontend development skill.
